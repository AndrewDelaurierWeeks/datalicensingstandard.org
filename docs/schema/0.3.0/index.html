The text that defines the fields is Annex A. To validate a declaration, from a folder holding these files:

python3 -m venv .venv
.venv/bin/pip install jsonschema rfc3339-validator
.venv/bin/python validate.py tdls-ai-vendor-declaration.schema.json example-declaration.json

The last command prints valid: example-declaration.json conforms to TDLS-AI Vendor Declaration (The Data Licensing Standard for AI, v0.1) (https://datalicensingstandard.org/schema/0.3.0/tdls-ai-vendor-declaration.schema.json). A declaration that validates has the right fields; validation scores nothing.
